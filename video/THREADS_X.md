# Threads no X (antigo Twitter) — regras do usuário

Objetivo: transformar roteiros dos vídeos (Shorts/longos) do canal **Último Abrigo** em threads narrativas virais.
Tom: sombrio, imersivo, **primeira pessoa**, tensão psicológica e medo.

## Estrutura (5 a 7 tweets, no máximo)
1. **Gancho:** curto e chocante (regra quebrada, descoberta bizarra, situação impossível).
   Termina SEMPRE com `🧵 (A thread)` + sugestão de mídia sombria.
2. **Desenvolvimento:** frases curtas, ritmo; detalhes sensoriais (frio, cheiro, sons, movimentos antinaturais).
   Nunca entregar o susto todo.
3. **Penúltimo (clímax):** maior tensão + cliffhanger angustiante.
4. **Último (conversão):** "este caso está documentado nos arquivos do Último Abrigo" + chamada para ação +
   espaço para o link + hashtags.

## Regras do algoritmo
- Link do YouTube **só no último tweet**.
- Em cada tweet: `(Dica de Mídia: ...)` dizendo qual frame/GIF/imagem escura do vídeo anexar.
- Hashtags obrigatórias no último: `#Terror #Suspense #Creepypasta #Sobrenatural #HistoriasDeTerror`
