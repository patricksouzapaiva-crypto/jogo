# Ep. 09 v4 "O que voltou da montanha" — pacote completo para recomeçar do zero

**Como gerar (igual antes):**
- **16:9**, na maior resolução, **2 variações** de cada (A e B).
- Cada prompt já está completo: é só copiar o bloco inteiro e colar.
- Não precisa renomear: mande os zips que eu organizo pelo código.

**O que mudou em relação ao pedido anterior (para não repetir os problemas):**
- Todo prompt termina com **"no timestamp, no date overlay, no phone interface"**. Antes, a IA inventava datas erradas e barras de celular.
- Placas e letreiros: **"no signs, no lettering"**. Antes, ela inventava um coreano que não existe.
- **Os personagens estão descritos sempre do mesmo jeito**, para não mudarem de uma imagem para outra:
  - **Lívia:** 19 anos, brasileira, cabelo preto liso comprido até o meio das costas, jaqueta corta-vento verde-oliva, legging preta, tênis brancos.
